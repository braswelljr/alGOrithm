# Catalog

Every algorithm, data structure and simulation in alGOrithm, generated from the registry (`go run ./tools/gendocs`), by topic and category. Each entry gives its cost, the Go function that implements it, and the command that runs its example; `algorithm info ID` says more, `algorithm source ID` prints the code, and the visualizer animates the ones marked animated.
